# Network Connectivity Troubleshooting

## Symptoms

Use this guide when a user cannot access the corporate network,
internet resources, or internal services from their workstation.

## Check Physical or Wireless Connectivity

For wired connections, verify that the network cable is securely
connected.

For wireless connections, confirm that Wi-Fi is enabled and that
the device is connected to the expected corporate network.

## Test Basic Connectivity

Open an approved internal or external web resource to determine
whether the problem affects all network access or only one service.

Record whether the device can reach any network resource.

## Restart the Network Connection

Disconnect and reconnect the affected network connection.

If required by the approved support procedure, restart the computer
and test connectivity again.

## Check IP Configuration

Review the device's network configuration and confirm that it has
a valid IP address and expected network settings.

Record any address or configuration error shown by the operating
system.

## Check DNS Resolution

If network access is available by IP address but corporate hostnames
do not resolve, test the organization's approved DNS configuration.

Record the hostname that failed and the resulting DNS error.

## Escalation

Escalate when connectivity remains unavailable after the local
connection, network configuration, and basic connectivity checks.

Include the affected device, network type, location, error message,
and whether other users are experiencing the same problem.
