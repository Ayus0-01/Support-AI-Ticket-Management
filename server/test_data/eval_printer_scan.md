# Printer Scanning Troubleshooting

## Symptoms

Use this guide when the scanning function of an approved multifunction printer or scanner is unavailable or does not complete successfully.

Common symptoms include:

- Scan function does not start
- Scanner is not detected
- Scan job fails
- Scanned output is not produced
- Scan operation stops unexpectedly

## Confirm the Device

Confirm that the multifunction printer or scanner is powered on and connected through the approved connection.

## Check Scanner Availability

Verify whether the workstation or approved scanning application detects the scanner.

Record any scanner-related error message.

## Check the Selected Device

Confirm that the correct approved printer or scanner is selected in the scanning application.

## Retry a Simple Scan

Perform a simple test scan using an approved document.

Determine whether the scan starts and completes successfully.

## Check the Connection

Verify that the workstation can communicate with the approved scanning device.

If other users also cannot scan using the same device, record that the issue may affect the shared device service.

## Restart the Application and Device

Close and reopen the approved scanning application.

If required by the approved support procedure, restart the workstation or multifunction device and test scanning again.

## Record Useful Information

Record:

- Device name or model
- Scanning application
- Connection type
- Scanner detection status
- Exact error message
- Whether a test scan succeeds
- Whether other users are affected

## Escalation

Escalate when scanning remains unavailable after device, application, selection, connection, and approved restart checks.

Include the device, application, exact error, test result, and scope of the problem.
