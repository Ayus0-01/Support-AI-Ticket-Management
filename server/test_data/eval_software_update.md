# Software Update Troubleshooting

## Symptoms

Use this guide when an approved corporate application requires an update, an update fails, or the application does not appear to have the expected approved version.

Common symptoms include:

- Application update fails
- Application reports that an update is required
- Approved update does not complete
- Application remains on an outdated supported version
- Update process reports an error

## Check the Current Version

Record the currently installed application version.

Confirm whether the installed version is still approved and supported by the organization.

## Check for an Approved Update

Use the organization's supported software-distribution or update process to determine whether an approved update is available.

Do not download updates from unknown or unapproved sources.

## Check Update Requirements

Record any prerequisite, storage, operating-system, connectivity, or permission error shown by the approved update process.

## Retry the Approved Update

Retry the update using the organization's supported process.

Do not repeatedly start the update when the system reports an active update process.

## Restart and Verify

After an approved update completes, restart the application if required and verify the installed version.

Perform a basic supported operation to confirm that the application works normally.

## Record Useful Information

Record:

- Application name
- Current version
- Target approved version when known
- Update error
- Update method used
- Operating-system version
- Whether other users are affected

## Escalation

Escalate when:

- The approved update repeatedly fails
- Required prerequisites are unavailable
- Administrative permission is required
- The application remains unsupported
- Multiple users experience the same update problem

## Important Safety Notes

Do not install unapproved software packages.

Do not disable security controls to complete an update.

Do not use unofficial update sources.

## Resolution Outcome

The expected outcome is installation of the approved supported application version or escalation when administrative intervention is required.

## Escalation

Escalation is recommended when the approved update process cannot complete successfully.
