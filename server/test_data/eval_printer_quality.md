# Printer Print Quality Troubleshooting

## Symptoms

Use this guide when a printer produces printed output but the output has visible quality problems.

Common symptoms include:

- Faded output
- Missing lines
- Streaks or marks
- Incorrect colors
- Uneven printing
- Other visible print-quality defects

## Check Printer Configuration

Confirm that the selected paper size, orientation, and approved print settings match the document being printed.

## Print a Test Page

Print an approved test page or simple test document.

Inspect the output for visible quality defects.

## Identify the Quality Problem

Record the specific problem observed, such as:

- Faded output
- Missing lines
- Streaks
- Incorrect colors
- Uneven output

## Test Another Approved Document

Print a simple document from another approved application when appropriate.

Determine whether the quality issue occurs across documents and applications.

## Check the Approved Printer Driver

Verify that the workstation is using the approved driver for the printer model.

Record the printer model and driver version when available.

## Check for Approved Driver Updates

Verify whether an approved driver update is available through the organization's supported software distribution process.

Do not install an unapproved driver from an unknown source.

## Record Useful Information

Record:

- Printer model
- Driver version when available
- Print settings
- Type of quality defect
- Test-page result
- Whether the problem affects multiple documents

## Escalation

Escalate when print quality remains incorrect after approved configuration and driver checks.

Include the printer model, driver version, observed quality defect, print settings, and test results.
