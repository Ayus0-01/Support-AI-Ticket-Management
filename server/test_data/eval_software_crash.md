# Software Crash Troubleshooting

## Symptoms

Use this guide when an approved corporate application crashes, closes unexpectedly, freezes, or becomes unresponsive during normal operation.

Common symptoms include:

- Application crashes unexpectedly
- Application closes without completing the requested action
- Application becomes unresponsive
- Application freezes during normal use
- The same action repeatedly causes the application to stop responding

## Record the Crash

Record:

- Application name
- Application version
- Operating-system version
- Exact error message when available
- Operation being performed when the crash occurred
- Whether the problem is repeatable

Do not rely only on a general description when a specific diagnostic message is available.

## Restart the Application

Close the application completely and reopen it.

Repeat the affected operation once to determine whether the problem occurs again.

## Restart the Workstation

If the application continues to crash, restart the workstation using the normal operating-system procedure.

Open the approved application again and test the affected operation.

## Check Whether the Problem Is Repeatable

Determine whether the crash happens during one specific operation or across multiple application functions.

Record the exact action that triggers the problem when it can be identified safely.

## Check the Approved Application Version

Verify that the installed application version is approved and supported by the organization.

Do not install an unapproved version as a troubleshooting shortcut.

## Record the Scope

Determine whether the issue affects only one user or whether other users experience the same application crash.

## Escalation

Escalate when:

- The application repeatedly crashes
- The crash occurs after normal restart procedures
- The cause cannot be identified safely
- Multiple users are affected
- Further application-level investigation is required

Include the application name, version, operating-system version, exact error, reproduction steps, and affected scope.

## Important Safety Notes

Do not modify application or operating-system settings without authorization.

Do not install unapproved software or versions to work around a crash.

## Resolution Outcome

The expected outcome is restoration of normal application operation or escalation with sufficient diagnostic information.

## Escalation

Escalation is recommended when repeated crashes require application-level investigation or administrative support.
