# VPN Connection and Timeout Troubleshooting

## Symptoms

Use this guide when the corporate VPN cannot establish a
connection or the connection attempt ends with a timeout.

## Verify Normal Network Access

Confirm that the device has working internet or approved network
connectivity before troubleshooting the VPN.

Open an approved external or internal resource and record whether
normal network access succeeds.

## Check the VPN Gateway

Verify that the VPN client is configured with the organization's
approved VPN gateway or server address.

Record the configured gateway if the connection continues to fail.

## Check the Timeout Message

Record the exact timeout message and the approximate time the
failure occurs.

Determine whether authentication succeeds before the timeout
or whether the connection fails earlier.

## Restart the VPN Client

Close the VPN client completely and reopen it.

Retry the VPN connection once after restarting the client.

If the user has already restarted the client, do not repeatedly
repeat the same step; continue with the remaining documented
checks.

## Test Another Approved Network

When possible, test the VPN from another approved network.

If the VPN works elsewhere, record the original network as a
possible source of the problem.

## Escalation

Escalate when the VPN continues to time out after network,
gateway, timeout-message, client-restart, and alternate-network
checks.

Include the exact timeout message, configured gateway, network
used, approximate failure time, and troubleshooting already
completed.
