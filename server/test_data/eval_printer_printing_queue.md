# Printer Printing and Queue Troubleshooting

## Symptoms

Use this guide when a printer is online but documents remain in
the print queue or do not print successfully.

## Check Printer Status

Confirm that the printer is powered on and connected to the
approved network or workstation.

Verify that the printer is not showing an offline, paused, or
error state.

## Check the Print Queue

Open the operating system print queue for the affected printer.

Check whether one or more jobs are stuck in a pending or error
state.

Record any message displayed for the failed print job.

## Retry the Print Job

Cancel only the affected failed job when appropriate and submit
a small test document.

Confirm whether the test document enters and leaves the queue
normally.

## Check the Selected Printer

Verify that the user is sending the document to the correct
printer.

If multiple printers are available, confirm that the expected
default or department printer is selected.

## Check Connectivity

Confirm that the workstation can reach the printer over the
approved network connection.

If other users cannot print to the same printer, record that
the issue may affect the shared printer service rather than a
single workstation.

## Escalation

Escalate when the printer remains unavailable after status,
queue, printer-selection, and connectivity checks.

Include the printer name, location, queue status, exact error
message, and whether other users are affected.
