# Software Error and Compatibility Troubleshooting

## Symptoms

Use this guide when an approved application displays an unexpected
error, behaves incorrectly after an update, or is incompatible
with the user's device environment.

## Record the Error

Record the exact error message, error code when available,
application version, and the operation that caused the failure.

Do not rely on a paraphrased error when the application displays
a specific diagnostic message.

## Restart the Application

Close the application completely and reopen it.

Repeat the failed operation once to determine whether the error
was temporary.

## Check the Application Version

Verify whether the installed application version is approved and
supported by the organization.

If an approved update is available, follow the supported software
update process.

## Check Compatibility

Verify that the application version is compatible with the
device's operating-system version and required supporting
components.

Record any compatibility warning.

## Test a Basic Operation

Perform a simple supported operation after restarting or updating
the application.

Compare the result with the original failure.

## Escalation

Escalate when the error continues after restart, approved updates,
and compatibility checks.

Include the application name, version, operating-system version,
exact error message, error code, and steps that reproduce the
problem.
