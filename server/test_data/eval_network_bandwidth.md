# Network Bandwidth Troubleshooting

## Symptoms

Use this guide when network performance is unusually slow, data transfers are taking significantly longer than expected, or network throughput appears reduced.

## Confirm the Affected Activity

Identify the specific activity experiencing slow network performance.

Examples include:

- File transfer
- Approved business application activity
- Internal resource access
- Other approved network operations

## Determine Whether the Problem Is Network-Specific

Check whether the slowdown affects one application or multiple network-dependent activities.

Record which activities are affected.

## Compare With Normal Performance

Determine whether the current performance is significantly different from normal expected behavior for the same network and activity.

## Check the Connection Type

Record whether the affected device is using approved Wi-Fi or wired LAN connectivity.

Determine whether the issue changes when using another approved network connection, when such a test is available.

## Determine the Scope

Check whether the bandwidth problem affects only one device or multiple users.

A problem affecting multiple users may indicate a broader network-performance issue.

## Avoid Repeated Large Transfers

Do not repeatedly start large transfers merely to test network performance when doing so could increase network load or affect business operations.

## Record Useful Information

Record:

- Device identifier when available
- Network type
- Location
- Affected activity
- Approximate performance behavior
- Time the issue occurred
- Whether other users are affected

## Escalation

Escalate when unusually slow network performance persists or affects multiple users or important business operations.

Include the device, network type, activity, location, observed behavior, time of occurrence, and scope of the problem.
