# Printer Driver Troubleshooting

## Symptoms

Use this guide when a printer is detected but produces incorrect
output, poor print quality, or driver-related errors.

## Check the Selected Driver

Verify that the workstation is using the approved driver for
the printer model.

Record the printer model and driver version when available.

## Check Printer Configuration

Confirm that the selected paper size, orientation, and print
settings match the document being printed.

Retry with a simple test document after correcting an incorrect
setting.

## Check for Approved Driver Updates

Verify whether an approved driver update is available through
the organization's supported software distribution process.

Do not install an unapproved driver from an unknown source.

## Test Another Application

Print a simple document from another approved application.

If printing works elsewhere, record the original application
as a possible source of the issue.

## Escalation

Escalate when the approved driver, printer settings, test-page
output, and alternate-application checks do not resolve the
problem.

Include the printer model, driver version, print settings,
observed output, and exact error message.
