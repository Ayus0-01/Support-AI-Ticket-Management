# Email Delivery and Spam Troubleshooting

## Symptoms

Use this guide when a user can access their mailbox but messages
are not being delivered, are delayed, or are being placed in the
wrong folder.

## Check the Recipient Address

Confirm that the recipient email address is correct and complete.

If the message is being sent to a distribution list, verify that
the user is authorized to send messages to that list.

## Check the Sent Folder

Confirm that the message appears in the user's Sent folder.

If the message is not present, retry the send operation and record
the exact error displayed by the email client.

## Check Spam and Junk Folders

Check the Spam or Junk folder for messages that the user expected
to receive.

If legitimate messages are being filtered, follow the organization's
approved process for reporting the message as not spam or allowlisting
the sender.

## Check Message Size

Verify that the message and its attachments are within the
organization's permitted size limits.

Remove unnecessary attachments or use an approved file-sharing
method when the attachment is too large.

## Check Delivery Errors

Review any non-delivery report, bounce message, or mail-server
error returned after sending.

Record the exact error code or message because it can identify
whether the failure is related to the recipient, sender, policy,
or mail service.

## Retry the Message

After correcting the recipient address, spam classification,
or message-size issue, send a new test message.

Confirm successful delivery before closing the ticket.

## Escalation

Escalate when messages continue to fail after the recipient,
spam filtering, message size, and delivery error checks have
been completed.

Include the sender address, recipient address, approximate time
of the message, exact delivery error, and whether the problem
affects other recipients.
