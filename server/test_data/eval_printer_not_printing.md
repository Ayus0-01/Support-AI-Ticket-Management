# Printer Not Printing Troubleshooting

## Symptoms

Use this guide when the printer is available but documents do not print successfully.

Common symptoms include:

- Print jobs do not produce printed output
- A document is submitted but nothing is printed
- The printer appears available but printing does not complete
- Small test documents also fail to print

## Check Printer Status

Confirm that the printer is powered on and connected to the approved network or workstation.

Verify that the printer is not showing an offline, paused, or error state.

## Check the Selected Printer

Verify that the user is sending the document to the correct approved printer.

If multiple printers are available, confirm that the expected printer is selected.

## Test a Small Document

Submit a small test document.

Determine whether the test document prints successfully or remains pending.

## Check the Print Queue

Open the operating system print queue for the affected printer.

Determine whether the print job is pending, paused, or showing an error.

Record any message associated with the failed job.

## Check Connectivity

Confirm that the workstation can communicate with the printer through the approved connection.

If other users also cannot print, record that the issue may affect the shared printer service.

## Retry After Basic Checks

After confirming printer status, selection, queue state, and connectivity, submit another small test document.

## Record Useful Information

Record:

- Printer name
- Printer location
- Printer status
- Queue state
- Exact error message
- Whether a test document prints
- Whether other users are affected

## Escalation

Escalate when the printer remains unable to produce output after status, printer-selection, queue, and connectivity checks.

Include the printer name, location, queue state, exact error, and scope of the problem.
