# Wi-Fi, LAN and DNS Troubleshooting

## Symptoms

Use this guide when a device has intermittent Wi-Fi, cannot obtain
a network connection, cannot communicate with local network
resources, or cannot resolve corporate hostnames.

## Check Wi-Fi Connection

Confirm that Wi-Fi is enabled and that the device is connected to
the expected corporate wireless network.

If the device is connected to the wrong network, reconnect to the
approved corporate network.

## Check Signal and Location

Determine whether the issue occurs only in the current physical
location.

When possible, move to an approved location with known network
coverage and test the connection again.

## Check Wired LAN Connection

For wired users, verify that the network cable is securely
connected and that the network adapter shows an active connection.

Test another approved network port when available.

## Check Local Network Access

Test access to an approved internal resource.

If local resources cannot be reached, record whether the problem
is limited to one device or affects multiple users.

## Check DNS Resolution

When network connectivity is present but corporate hostnames do
not resolve, verify the configured DNS servers using the approved
network settings.

Record the hostname and exact DNS error.

## Retry the Connection

After correcting the connection or DNS configuration, reconnect
to the network and test both an approved internal resource and
normal internet access.

## Escalation

Escalate when Wi-Fi or LAN connectivity continues to fail after
connection, location, port, and DNS checks.

Include the device, network type, location, hostname if relevant,
exact error, and whether other devices are affected.
