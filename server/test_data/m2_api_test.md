## VPN Timeout Troubleshooting

When a VPN connection times out, first verify that the device has
working network connectivity and that normal web access is available.
Confirm that the VPN client is connected to the correct corporate
server and that the configured gateway is reachable.

Check firewall rules, authentication settings, certificates, and the
approved VPN protocol. Restart the VPN client after correcting stale
credentials or configuration values.

If the documented troubleshooting steps do not resolve the issue,
collect the client logs, exact timeout message, server address, and
time of failure. Escalate the issue to the appropriate support team
with the collected evidence.
