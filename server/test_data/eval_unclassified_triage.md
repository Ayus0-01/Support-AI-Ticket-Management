# Unclassified Issue Triage

## Symptoms

Use this guide when a support request is valid but does not
clearly belong to one of the defined technical categories.

## Confirm the User Impact

Determine whether the requester is unable to work, partially
blocked, or able to continue with a workaround.

Record whether other users are affected.

## Identify the Observable Behavior

Capture the visible behavior instead of guessing the underlying
cause.

Record exact error messages, affected screens, device names,
application names, or service names when available.

## Determine Recent Changes

Ask whether the issue began after a software update, configuration
change, password change, device change, network change, or another
known event.

Record the timing and nature of the change.

## Use Existing Documentation Carefully

Search the knowledge base using the specific observable symptoms.

Only recommend documented actions from an article that clearly
matches the reported issue.

Do not combine unrelated procedures merely because their category
appears similar.

## Escalation

Escalate when the available information is insufficient to
identify the problem or when no published knowledge article
provides a supported troubleshooting procedure.

State which information or documentation is missing so the next
support level can continue diagnosis.
