# New User Onboarding Access Troubleshooting

## Overview

This article provides troubleshooting guidance for access problems experienced by newly onboarded users.

## Symptoms

Common symptoms include:

- A newly onboarded employee cannot access a required system
- Expected company applications are unavailable
- The user can authenticate but cannot access a required resource
- Required onboarding access has not been provisioned
- The user is unsure which systems should be available

## Troubleshooting Steps

### 1. Identify the required resource

Confirm the exact application, account, system, or resource that the new user is expected to access.

### 2. Confirm the corporate account

Verify that the user has the expected company account and is using the correct corporate identity.

### 3. Confirm expected access

Determine which systems and applications should be available based on the user's role and department.

### 4. Test the affected resource

Attempt to access the required resource using the approved company account.

Record any authentication, permission, or provisioning message shown.

### 5. Determine whether access was provisioned

If the user has never previously accessed the system, determine whether the required entitlement has actually been provisioned.

### 6. Follow the approved onboarding process

If required access has not been provisioned, follow the organization's approved onboarding or provisioning workflow.

### 7. Escalate incomplete provisioning

Escalate when:

- Required access was not provisioned
- The user account was not created correctly
- Administrative provisioning is required
- The user's expected access cannot be determined
- Required onboarding information is missing

## Important Safety Notes

Do not bypass access controls.

Do not grant elevated permissions as a shortcut.

Do not create unauthorized accounts or permissions.

## Resolution Outcome

The expected outcome is correct provisioning of the systems and resources required for the user's role.

## Escalation

Escalation is recommended when onboarding provisioning or administrative access changes are required.
