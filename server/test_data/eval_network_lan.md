# LAN Troubleshooting

## Symptoms

Use this guide when a workstation cannot communicate over the approved wired local area network.

## Check the Network Cable

Verify that the network cable is securely connected to the workstation and the approved network port.

## Check the Network Adapter

Confirm that the wired network adapter shows an active connection.

Record any connection status or operating-system error.

## Test Another Approved Port

When available, connect the workstation to another approved network port and test the connection again.

Record whether the problem changes when another port is used.

## Test Local Network Access

Open an approved internal resource to determine whether the workstation can communicate with the local corporate network.

## Determine the Scope

Check whether the issue affects only the current workstation or whether other users on the same local network are experiencing the same problem.

## Restart the Network Connection

Disconnect and reconnect the wired network connection.

If required by the approved support procedure, restart the workstation and test again.

## Record Useful Information

Record:

- Device identifier when available
- Network type
- Network location
- Port used
- Connection status
- Exact error
- Whether other devices are affected

## Escalation

Escalate when wired LAN connectivity remains unavailable after cable, adapter, port, and basic connectivity checks.

Include the workstation, network location, port information, exact error, and scope of the issue.
