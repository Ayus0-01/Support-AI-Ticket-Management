# Software Installation and Configuration Troubleshooting

## Symptoms

Use this guide when an approved corporate application cannot be
installed, configured, or started after installation.

## Verify the Approved Software

Confirm that the user is installing the approved application and
the correct version for the device.

Do not install software from an unapproved or unknown source.

## Check Installation Requirements

Verify that the device has sufficient storage and that the
operating system meets the application's supported requirements.

Record any prerequisite or compatibility error displayed during
installation.

## Retry the Installation

Close other applications that may interfere with installation.

Run the approved installation package again using the organization's
supported installation process.

Record the exact error if the installation fails again.

## Check Application Configuration

After installation, verify that required server addresses,
account settings, or other documented configuration values are
correct.

Do not change undocumented configuration settings.

## Test the Application

Launch the application and perform a basic supported operation.

Confirm whether the application starts normally and can connect
to its required corporate service.

## Escalation

Escalate when the approved installer repeatedly fails, required
prerequisites are unavailable, or the application cannot be
configured using the documented settings.

Include the application name, version, device information,
installation error, and configuration error when applicable.
