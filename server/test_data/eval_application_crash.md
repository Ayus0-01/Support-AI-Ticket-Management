# Application Performance Troubleshooting

## Overview

This article provides troubleshooting guidance for corporate applications that are slow, freeze, become unresponsive, or perform poorly during normal use.

## Symptoms

Common symptoms include:

- Application response is slow
- Screens take a long time to load
- The application becomes temporarily unresponsive
- Normal actions take unusually long to complete
- Application performance has degraded compared with normal operation

## Troubleshooting Steps

### 1. Confirm the affected application

Identify the exact corporate application experiencing the performance problem.

Record the affected function or screen when possible.

### 2. Confirm whether the issue is isolated

Determine whether the performance problem affects only one application or multiple applications on the workstation.

### 3. Restart the application

Close the affected application completely and start it again.

Retry the operation that was previously slow or unresponsive.

### 4. Check whether the problem persists

Repeat the affected operation after restarting the application.

Note whether the same performance problem occurs consistently.

### 5. Restart the workstation when appropriate

Restart the workstation and retry the affected application.

### 6. Record useful symptoms

Record observable details such as:

- Which application is affected
- Which function is slow
- Whether the application freezes
- Whether the issue is intermittent or continuous
- Whether other applications remain responsive

### 7. Escalate persistent performance problems

Escalate when:

- The application remains slow after normal troubleshooting
- The application repeatedly becomes unresponsive
- Multiple users are experiencing the same performance problem
- The affected function cannot be identified
- Further administrative or application-level investigation is required

## Important Safety Notes

Do not modify application configuration, system settings, or security controls unless the action is explicitly authorized.

Do not disable security or monitoring controls as a performance workaround.

## Resolution Outcome

The expected outcome is restoration of normal application responsiveness.

## Escalation

Escalation is recommended when normal user-level troubleshooting does not restore acceptable application performance or when broader application investigation is required.
