# Password and Account Recovery

## Symptoms

Use this guide when a user has forgotten a company password
or cannot access the account because the password is no longer
known.

## Confirm the Account

Confirm the affected username and verify that the user is
attempting to access the correct company account.

Do not ask the user to create a second account when the problem
is an existing corporate account.

## Use the Approved Password Reset Process

Open the organization's approved password-reset or account-recovery
portal.

Complete identity verification using the authentication method
required by the organization.

Set a new password that satisfies the organization's password
requirements.

## Test the New Password

After resetting the password, wait for the change to propagate
if the organization uses centralized identity services.

Sign in again using the new password.

If the user has multiple devices, verify that the new credentials
work on the primary corporate service before updating saved
credentials elsewhere.

## Escalation

Escalate the ticket when the user cannot complete identity
verification, the reset process reports an account-side error,
or the account remains inaccessible after a successful reset.

Include the username, exact error message, and time of the
failed login attempt in the escalation.
