# Suspicious Activity Troubleshooting

## Overview

This article provides guidance for situations where a user observes unusual or potentially unauthorized activity that does not clearly represent a phishing message or confirmed malware event.

## Symptoms

Common symptoms include:

- Unexpected login notifications
- Unfamiliar applications or activity
- Unexpected changes to account or system behavior
- Unusual pop-ups or system behavior
- Activity the user does not recognize
- Other signs that an account, device, or resource may be being used unexpectedly

## Record the Activity

Record the observable activity, including:

- Exact message or alert
- Approximate time
- Affected account, application, or device
- Unfamiliar activity observed
- Any related security warning

Do not delete potentially useful security evidence unless the approved procedure instructs the user to do so.

## Avoid Further Risk

Do not continue interacting with unfamiliar applications, links, files, or security prompts when doing so could increase risk.

Do not disable approved security controls.

Do not attempt to investigate potentially unauthorized activity by performing additional risky actions.

## Check Whether the Activity Is Recognized

Determine whether the activity can be confirmed as an expected action, system notification, or approved business process.

If the activity cannot be explained, preserve the available details.

## Determine the Scope

Record whether the unusual activity appears limited to one account or device or whether similar activity is affecting other users.

## Report Suspicious Activity

Use the organization's approved security-incident reporting process when activity remains unexplained or appears potentially unauthorized.

Include the observed activity, affected account or device, approximate time, and actions already taken.

## Escalation

Escalate when:

- Activity appears unauthorized
- An account may have been compromised
- Unfamiliar access continues
- Security controls report suspicious activity
- The cause cannot be established safely
- Additional security investigation is required

## Important Safety Notes

Do not bypass security controls.

Do not attempt unauthorized account or system investigation.

Do not delete security evidence without authorization.

## Resolution Outcome

The expected outcome is identification of the activity as expected behavior or reporting and escalation through the approved security process when it remains unexplained.

## Escalation

Escalation is recommended when suspicious activity may indicate unauthorized access or another security incident.
