# Peripheral and Input Device Troubleshooting

## Overview

This article provides troubleshooting guidance for external and connected computer peripherals used with company workstations and laptops.

Peripheral devices include keyboards, mouse devices, headsets, webcams, external input devices, and other approved USB or connected devices.

## Symptoms

Common symptoms include:

- Keyboard is not responding
- External keyboard is not responding
- USB keyboard is not working
- Mouse is not responding
- External mouse is not working
- USB mouse is not working
- Headset is not detected or not working
- USB headset is not working
- Webcam is not detected
- USB peripheral is not recognized
- External input device stops responding
- Peripheral works intermittently
- A connected peripheral is unavailable to an application

## Troubleshooting Steps

### 1. Identify the affected peripheral

Confirm the exact peripheral that is not working.

Examples include:

- Keyboard
- External keyboard
- USB keyboard
- Mouse
- External mouse
- USB mouse
- Headset
- USB headset
- Webcam
- External input device
- USB peripheral

### 2. Check the physical connection

For wired peripherals, verify that the device is securely connected to the workstation or laptop.

For USB devices, verify that the USB connection is secure.

For wireless peripherals, verify that the approved wireless connection is active and that the device is powered on.

### 3. Reconnect the peripheral

Disconnect the affected peripheral and reconnect it securely.

For USB peripherals, reconnect the device using an approved compatible port.

If an approved alternative connection is available, test the peripheral through that connection.

### 4. Restart the workstation

Restart the computer and reconnect the affected peripheral after the system starts.

Test the peripheral again after the operating system has fully loaded.

### 5. Check whether the peripheral is detected

Determine whether the workstation recognizes the peripheral.

Record whether the device appears intermittently, remains unavailable, or is detected but does not respond.

For USB devices, record whether the operating system detects the USB peripheral.

### 6. Test another approved peripheral when available

When safe and appropriate, determine whether another compatible peripheral works with the same workstation.

For example, an approved known-working keyboard, mouse, headset, or other compatible peripheral can be tested on the same computer.

This helps distinguish a device-specific issue from a workstation-side issue.

### 7. Determine whether the issue affects one peripheral or multiple devices

If multiple external peripherals fail simultaneously, record that information because broader workstation or connectivity investigation may be required.

If only one peripheral fails while another compatible peripheral works correctly, record that comparison.

### 8. Record useful diagnostic information

Record:

- Peripheral type
- Device name or identifier when available
- Connection type
- Whether the device is wired or wireless
- Whether the device uses USB
- Observable symptoms
- Whether the problem is intermittent or continuous
- Whether the operating system detects the device
- Whether another compatible peripheral works

### 9. Escalate persistent peripheral issues

Escalate when:

- The peripheral remains undetected
- Reconnecting and restarting do not resolve the issue
- Physical damage is suspected
- Multiple peripherals fail unexpectedly
- Hardware replacement may be required
- Further administrative or hardware investigation is necessary

## Important Safety Notes

Do not disassemble or physically repair peripherals unless authorized.

Do not install unapproved hardware or software as a troubleshooting shortcut.

Do not bypass device-management or security controls.

Do not repeatedly reconnect or operate damaged hardware when doing so could create a safety risk.

## Resolution Outcome

The expected outcome is restoration of normal operation for the affected peripheral.

If the peripheral remains unavailable after reconnecting, restarting, and approved peripheral or port tests, escalate for further hardware investigation or approved replacement.

## Escalation

Escalation is recommended when the device remains unavailable, physical damage is suspected, multiple peripherals are affected, or hardware intervention is required.
