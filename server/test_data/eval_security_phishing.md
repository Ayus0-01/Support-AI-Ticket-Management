# Phishing Report Troubleshooting

## Overview

This article provides guidance for users who receive a suspicious email or message that may be attempting to collect credentials, deliver malicious content, or impersonate a trusted person or service.

## Symptoms

Common symptoms include:

- Suspicious email or message
- Message asks for credentials or sensitive information
- Unexpected links or attachments
- Sender appears to impersonate a trusted person or service
- Message requests an unusual or unexpected action

## Do Not Interact With the Message

Do not click suspicious links, open unexpected attachments, or enter credentials into a page reached from the suspicious message.

Do not reply to the sender to verify the request.

## Record the Message Details

Record the sender address, subject, approximate arrival time, and any suspicious link or attachment name.

Preserve the message using the organization's approved reporting process.

## Report the Message

Use the organization's approved phishing-reporting or security incident process.

Include the original message or approved security-reporting metadata when requested.

## If a Link Was Opened

If the user already opened a suspicious link, stop interacting with the page and report the event through the approved security incident process.

Do not continue entering information to determine whether the message is malicious.

## If Credentials Were Submitted

If the user entered corporate credentials into a suspicious page, report the event immediately through the approved security incident process.

Do not reuse the suspicious page or attempt additional tests against it.

## Escalation

Escalate immediately when:

- A suspicious attachment was opened
- Corporate credentials were submitted
- Suspicious software executed
- Sensitive information may have been exposed
- The message may represent a broader security incident

Include the message details, user actions taken, approximate time, and any visible security warning.

## Important Safety Notes

Do not interact further with suspicious messages.

Do not attempt to investigate suspicious links or attachments manually.

Do not provide credentials or sensitive information in response to suspicious messages.

## Resolution Outcome

The expected outcome is that the suspicious message is safely reported through the organization's approved security-reporting process.

## Escalation

Escalation is recommended whenever user interaction with the suspicious message may have resulted in credential exposure, malicious execution, or other security impact.
