# Software Compatibility Troubleshooting

## Symptoms

Use this guide when an approved application does not function correctly because its version, operating system, or supporting components may be incompatible.

Common symptoms include:

- Application reports a compatibility error
- Application does not support the current operating-system version
- A required supporting component is unavailable
- Application behavior changes after an operating-system or software change
- Installation or startup reports a compatibility warning

## Identify the Application

Record the application name and installed version.

## Check the Operating System

Record the workstation's operating-system version.

Verify whether the approved application version supports that operating-system version.

## Check Supporting Components

Identify any documented supporting component or prerequisite associated with the application.

Record any compatibility warning displayed by the approved application or installation process.

## Verify the Approved Version

Confirm that the installed application version is approved and supported by the organization.

Do not install an unapproved version simply to bypass a compatibility problem.

## Test a Basic Operation

After approved changes or updates, perform a simple supported operation.

Determine whether the compatibility problem persists.

## Record Useful Information

Record:

- Application name
- Application version
- Operating-system version
- Supporting components when relevant
- Exact compatibility message
- Operation affected
- Any approved update or configuration already attempted

## Escalation

Escalate when:

- The application remains incompatible
- Required supporting components are unavailable
- Administrative software changes are required
- The supported application and operating-system versions do not align
- Further application investigation is required

## Important Safety Notes

Do not bypass compatibility protections.

Do not install unsupported software versions.

Do not modify operating-system settings without authorization.

## Resolution Outcome

The expected outcome is operation of a supported application version in a compatible environment or escalation when further changes are required.

## Escalation

Escalation is recommended when compatibility cannot be resolved through approved user-level procedures.
