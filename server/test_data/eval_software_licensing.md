# Software Licensing Troubleshooting

## Symptoms

Use this guide when an approved corporate application reports a licensing, activation, subscription, or entitlement problem.

Common symptoms include:

- Application reports that a license is unavailable
- Activation fails
- Application reports an expired or invalid license
- A licensed feature is unavailable
- The user is prompted repeatedly for activation
- The application reports an entitlement problem

## Identify the Application

Confirm the application name and installed version.

Record the exact licensing or activation message displayed.

## Verify the Approved Application Version

Confirm that the installed application version is approved and supported by the organization.

## Check the User's Approved Entitlement

Use the organization's approved process to determine whether the user is expected to have access to the application or feature.

Do not attempt to bypass licensing controls.

## Check Connectivity When Required

If the approved licensing process requires communication with an organizational licensing service, confirm that the workstation has its expected network connectivity.

Record any licensing-service error shown by the application.

## Retry Activation Through the Approved Process

Retry the licensing or activation operation using the organization's supported procedure.

Do not use unauthorized activation tools or license keys.

## Record Useful Information

Record:

- Application name
- Application version
- Licensing or activation message
- User or account context through the approved process
- Whether the issue affects one user or multiple users

## Escalation

Escalate when:

- Licensing remains unavailable
- The user's entitlement cannot be confirmed
- Administrative activation is required
- A licensing service may be unavailable
- The licensing configuration requires authorized changes

## Important Safety Notes

Do not use unauthorized license keys.

Do not bypass activation or licensing controls.

Do not install unofficial activation tools.

## Resolution Outcome

The expected outcome is successful activation through the organization's approved licensing process or escalation when entitlement or administrative intervention is required.

## Escalation

Escalation is recommended when licensing cannot be restored through approved user-level procedures.
