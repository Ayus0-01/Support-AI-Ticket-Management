# Wi-Fi Troubleshooting

## Symptoms

Use this guide when a device cannot connect to the expected corporate Wi-Fi network, repeatedly disconnects, or has unstable wireless connectivity.

## Check Wi-Fi Connection

Confirm that Wi-Fi is enabled and that the device is connected to the expected corporate wireless network.

If the device is connected to the wrong network, reconnect to the approved corporate network.

## Check Signal and Location

Determine whether the issue occurs only in the current physical location.

When possible, test the connection from another approved location with known network coverage.

## Disconnect and Reconnect

Disconnect from the corporate Wi-Fi network and reconnect using the approved network credentials or connection method.

## Restart the Wireless Connection

Disable and re-enable Wi-Fi using the normal operating-system controls.

If required by the approved support procedure, restart the computer and test the connection again.

## Check Another Approved Device

When available, determine whether another approved device can connect to the same corporate Wi-Fi network.

Record whether the issue appears limited to one device or affects multiple devices.

## Record Useful Information

Record:

- Device identifier when available
- Corporate Wi-Fi network
- Physical location
- Whether the connection is intermittent or unavailable
- Any operating-system error
- Whether other devices are affected

## Escalation

Escalate when Wi-Fi remains unavailable after reconnecting, checking location, and restarting the wireless connection.

Include the device, network name, location, exact error, and whether other devices are affected.
